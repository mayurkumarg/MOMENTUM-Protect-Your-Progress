## 🚀 Ready to Test

### Start Testing (5 minutes)

1. **Start Backend**
   ```bash
   cd backend
   npm run dev
   ```

2. **Start Frontend** (new terminal)
   ```bash
   cd frontend
   npm run dev
   ```

3. **Open Browser**
   ```
   http://localhost:5173/register
   ```

4. **Test Flow**
   - Register new account
   - Verify redirected to /overview
   - Check profile menu shows username
   - Click logout
   - Login with same credentials
   - Verify authenticated
